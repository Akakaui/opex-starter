## When This Domain Applies

Auto-loads when creating content about starting a business, making money from scratch, entrepreneurship mindset, or overcoming the starting-block. Specifically:

| If the user asks about... | Load this |
|--------------------------|-----------|
| Starting with no money | Skills First framework |
| Feeling stuck or blocked | Use What You Have framework |
| Competitors outpacing them | Volume Negates Luck framework |
| How money works in business | Voluntary Exchange framework |
| Scaling or hiring | Time-buying mindset |
| Not making sales yet | First sale = learning framework |
| Needing the right mindset | Meet success where you are |

## How to Apply

When generating content for entrepreneurship or starting out:

1. If the piece is about STARTING: lead with Skills First (buy skills not things)
2. If the piece is about EXCUSES: inject Use What You Have (stop waiting)
3. If the piece is about COMPETITION: apply Volume Negates Luck (100x not 2x)
4. If the piece is about BUSINESS BASICS: use Voluntary Exchange (give first)
5. If the piece is about NOT SELLING yet: remind them first sale is practice
6. If the piece is about SCALING: shift focus to buying time via other people
