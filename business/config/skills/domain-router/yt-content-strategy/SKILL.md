## How to Apply

When generating content briefs for YouTube strategy:

1. If the piece is about INTROS or HOOKS: inject Proof-Promise-Plan structure
2. If the user is choosing TOPICS: remind them to narrow, not widen
3. If the user is deciding FORMAT: recommend long-form for business, shorts for reach
4. If tracking RESULTS: use RPM, not raw views
5. If writing copy: prioritize clear language over clever production
6. If the piece addresses new viewers: use stranger-first framing
