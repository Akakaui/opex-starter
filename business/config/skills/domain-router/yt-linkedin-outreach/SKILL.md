## How to Apply

1. If writing DM copy: sell the outcome not the offering
2. If choosing targets: segment first, let replies validate who cares
3. If writing first message: make it a gift with no ask
4. If following up: voice note + resource + check-in spread across a week
5. If not seeing results: increase volume but only after fixing targeting and offer
6. If using AI: personalize per-profile (not just first-name swaps)
