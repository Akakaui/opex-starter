When generating content for customer acquisition:

2. If the piece is about TEAM: push Fewer Better (A-player leverage)
3. If the piece is about STRATEGY: use Reverse Engineer Number One
4. If the piece is about CONTENT: inject Pre Over Post (idea > editing)
5. If the piece is about OFFERS: audit Need to Believes (max 1)
6. If the piece is about CONVERSION: apply Split Test Priority Order
7. If the piece is about GROWTH: use LTV Arms Race (raise prices to spend more)
8. If the piece is about COPY: apply Truth as Strategy (damaging admission formula)
9. If the piece is about PARTNERSHIPS: Make Affiliates So Good It Hurts
