# Create Video

Create video content based on: $ARGUMENTS

## Process
1. Ask: Reel, Short, YouTube, or TikTok?
2. Ask: What style? (faceless, talking head, screen, hybrid)
3. Write script (what to say)
4. Write scene plan (what to show)
5. Write asset list (what to upload)
6. Present to user
7. Update video tracker
