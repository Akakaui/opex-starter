# Create Video

Create video content based on: $ARGUMENTS

## Process
1. Load voice rules from `business/memory/04-human-voice-rules.md`
2. Load schedule from `business/memory/02-posting-schedule.md`
3. Load goals from `business/memory/03-goals-and-missions.md`
4. Ask: Reel, Short, YouTube, or TikTok?
5. Ask: What style? (faceless, talking head, screen, hybrid)
6. Write script (what to say)
7. Write scene plan (what to show)
8. Write asset list (what to upload)
9. Present to user
10. Update video tracker
