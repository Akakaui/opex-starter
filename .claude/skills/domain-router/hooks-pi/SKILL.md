## How to Apply

1. If the piece needs to STOP THE SCROLL: pick a pattern from the hooks-pi library that matches the content type
2. For AUTHORITY content: use contrarian statements, direct address, or proof-first hooks
3. For EDUCATIONAL content: use curiosity gap or specific-result hooks
4. For SALES content: use pain-point-first or desire-based hooks
5. Always match the hook to the platform's native format (short for Reels/Shorts, longer for LinkedIn/YT)
6. The first 1-3 seconds determine retention — no warm-up allowed
