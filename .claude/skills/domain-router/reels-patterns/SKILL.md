## How to Apply

1. Pick a hook pattern that matches the content type (authority, educational, entertainment)
2. Apply the hook in the first 0-3 seconds — no warm-up in short-form
3. Match hook effectiveness to audience awareness level
4. Use specific numbers + timeframe + vague-result for curiosity gaps
5. Use 'you' or 'if you' for direct address — must match target audience behavior exactly
